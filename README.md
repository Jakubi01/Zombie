# ZOMBIE : NEW FEATURE LIST

## 1. Mouse Rotate
### You can rotate the character using the mouse.

## 2. Kill Streak
### A kill streak activates once you collect a certain number of points.

## 3. Dash
### You can dash in the desired direction.

## 4. Wave StandBy Time
### Wait for a certain period after the wave ends.

## 5. Shop
### You can use the shop during the wave wait time.
